# 我的一天，消耗多少能源？

高中地理（108 課綱・社會環境議題・能源單元）互動式每日能源消耗計算器。
學生輸入日常生活行為，估算個人每日**終端能源**消耗量（kWh／MJ），辨識能源載體，並延伸理解臺灣電力結構與能源進口依賴。

> 本工具**不是碳足跡計算器**，不計算碳排放量。

## 使用方式

| 指令 | 說明 |
| --- | --- |
| `npm install` | 第一次使用時安裝套件 |
| `npm run dev` | 開發模式，開啟 http://localhost:5173 |
| `npm test` | 執行計算引擎單元測試 |
| `npm run build` | 建置靜態網站到 `dist/` |

`dist/` 資料夾可直接放到學校網站、GitHub Pages 或任何靜態主機的子目錄。之所以能這樣放，是因為 `vite.config.ts` 設定了 `base: './'`。
網站全部在瀏覽器端運算，不需要後端，也不需要登入。

## 網站流程

1. **開始探索**：說明本工具的定位與限制
2. **輸入資料**：A 家庭用電、B 交通、C 烹調燃料、D 其他（可載入示範情境）
3. **計算結果**：
   - 摘要卡片
   - 能源載體甜甜圈圖、活動長條圖
   - 計算明細與公式
   - 前三大來源
   - 臺灣能源結構
   - 探究問題
4. **情境比較**：複製原始情境後調整參數，並排比較差異

其他功能：CSV 匯出（含 BOM，Excel 可正確顯示中文）、列印、localStorage 自動儲存、重設。

## 計算口徑

- 電力：`kWh = kW × 小時 × 負載比例 ÷ 分攤人數`，`1 kWh = 3.6 MJ`
- 燃料：`MJ = 燃料量 × 熱值`。熱值依能源署熱值表，分別為汽油 7,800 kcal/L、柴油 8,400 kcal/L、天然氣 9,000 kcal/m³、LPG 12,000 kcal/kg
- 大眾運輸：以「每人每公里」估算個人分攤量，可選擇是否計入總量
- 總量只加總終端能源，**不**與發電端一次能源相加，避免重複計算
